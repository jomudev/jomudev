## Featured Case Study: Lili Delivery *(Production Multi-Role Ecosystem)*

<p align="center">
  <img src="https://raw.githubusercontent.com/jomudev/portfolio/main/public/res/lili_preview_screenshot.jpg" alt="Lili Delivery Preview" width="760" />
</p>

An end-to-end on-demand delivery ecosystem comparable to DoorDash / PedidosYa across private production repositories (`liliDeliveryClientSide`, `liliDeliveryDriver`, `DeliveryTestingAPI_REST`, `numada`, `sockets`):

- **4 Dedicated User Workflows:** Customer App, Driver/Courier App, Partner Merchant Operations, and Admin Controls.
- **Real-Time Geolocation & Dispatch:** Background location tracking, dynamic route directions (`react-native-maps`, `expo-location`, `@googlemaps/routing`), and live order state sync over **Socket.io**.
- **Multi-Gateway Payments:** **Stripe** (`@stripe/stripe-react-native`), **Mercado Pago**, **PayPal**, and verified bank-transfer receipt workflows with webhook confirmation.
- **Production Observability & Store Delivery:** **Firebase** (Auth, Firestore, FCM Push Notifications, Crashlytics, Analytics), **LogRocket**, **i18next**, Docker / Fly.io CI/CD, and releases to **Apple App Store & Google Play Store**.
